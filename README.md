# Wedding Planner UI (Angular)

## Run locally
1. Install Node.js 18+.
2. In this folder:
   ```bash
   npm install
   npm start
   ```
3. Open http://localhost:4200

## Features
- Invites: Excel upload (XLSX), manual adds/edits, RSVP tracking
- Budget: total budget, expenses, remaining amount
- Checklist: tasks + owner + due date
- Calendar: month selector + appointments list (planner / venue / providers)
- Seating: define tables, drag & drop RSVP YES guests, export CSV

## Excel template (recommended columns)
Party, FirstName, LastName, Email, Phone, RSVP, MealChoice, Notes
